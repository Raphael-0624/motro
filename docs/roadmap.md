# 阶段路线图

## 阶段 1：本地最小可用版本

- [x] 三模块目录、npm workspace、Git 和开发文档。
- [x] 服务端托管手机网页，WebSocket 配对和转发。
- [x] 四位码、电脑确认、短期令牌、断线恢复。
- [x] 手机触控区域、单指滚动、双指缩放、速度调节。
- [x] Chrome/Edge MV3 扩展，当前标签页滚动和原生缩放。
- [x] 服务端集成测试与浏览器端到端测试脚本。
- [x] 极简分状态界面，居中连接码，手机一屏大触控区。
- [x] 二维码自动申请，跳过输入但保留电脑授权。
- [x] 轻量滚动惯性，触摸立即停止，后台心跳保持连接。
- [x] 无调试权限的 DOM 分轴滚动，手机「上下 / 左右」切换与嵌套容器回归测试。
- [x] 持久化粗略访问序号、统一版本递增和部署 Agent 任务。
- [ ] 用户手机真机验收：iOS/Android、Wi-Fi、休眠、方向与手感。

## 阶段 2：体验与兼容性

- [ ] 根据真机体验进一步调节手势灵敏度、缩放节流和轻量惯性参数。
- [ ] 更明确的目标窗口选择、长连接状态和错误反馈。
- [ ] iframe、PDF、复杂滚动容器等兼容性清单及适配。
- [ ] 普通网站和嵌套滚动区域真机手感验收；无调试权限方案不保证飞书 Canvas 文档。
- [ ] 连接确认的设备标识或额外核对信息。
- [x] 接入品牌图标：插件工具栏、管理页、弹窗及手机网页。
- [ ] 打包分发、稳定扩展 ID 与权限说明。

## 阶段 3：远程部署

- [ ] 明确测试域名、服务器、证书与访问控制。
- [ ] 单实例 HTTPS/WSS 部署、可信代理限流、安全复核。
- [ ] 公网端到端测试、延迟和异常断线观察。
- [ ] 如需要公开多用户使用，再引入更强认证、全局防滥用和可观测性。

暂不做：远程桌面、电脑画面推流、操作系统级鼠标键盘控制、多手机协同、账户系统和多实例扩容。
